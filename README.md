## 🚀 Featured Project

### REGISSION - Smart IoT Chessboard with Camera-Based Move Detection

REGISSION is a vision-based Smart IoT chessboard that detects physical chess moves automatically using a Raspberry Pi 5, YOLOv8, OpenCV and python-chess, then records and displays the game through a Laravel, MySQL and Next.js web system.

- 🌐 **Live System:** https://regission-143-198-196-49.sslip.io/
- 💻 **Repository:** https://github.com/ipannajmii/REGISSION
- 🤖 YOLOv8 board segmentation and chess-piece detection
- 📷 Raspberry Pi camera-based move detection
- 🔄 OpenCV perspective transformation and frame differencing
- ♟️ python-chess legal move validation and SAN generation
- ☁️ Laravel + MySQL + Next.js deployed on DigitalOcean
- 📊 Stockfish 18 analysis and OpenAI move explanations
